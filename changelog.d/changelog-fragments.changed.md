- **Check 3 of `scripts/check_version_and_changelog.py` accepts a fragment in `changelog.d/` as the changelog trace.** Until now a non-trivial commit after the last release tag without a version bump needed an `## [Unreleased]` heading in CHANGELOG.md, or the gate ended with exit 1. A fragment named `<stem>.<section>.md` in `changelog.d/` now satisfies the check too, so the gate ends with exit 0 where it found such a fragment. Without a fragment the verdict is unchanged; the finding now reads "no `## [Unreleased]` section and changelog.d/ no fragment".

- **`scripts/changelog_fragments.py` checks and collects CHANGELOG fragments, standard library only.** A pull request may write its CHANGELOG lines as one file per section in `changelog.d/` instead of under `## [Unreleased]`, so two open pull requests no longer conflict in CHANGELOG.md. `check` ends with exit 1 on a bad name, an unknown section, an empty file or content that breaks the structure; `collect` moves every fragment under `## [Unreleased]` at the release cut, by section and then by file name. Writing directly under `## [Unreleased]` stays valid.

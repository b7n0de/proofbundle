  release CI matrix, including the required Rust verifier, and the mutation layer on C. Run MST1 and LAB1 on C. Record
  the commit and run identifiers and confirm that the required jobs actually completed successfully. Earlier heads,

  the previous one. Collect the pre-tag receipt and the owner's signature for C and its evidence before tagging.

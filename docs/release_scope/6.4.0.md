# Release scope — 6.4.0 (MINOR)

Written before the release, per the release gate in [RELEASE.md](../../RELEASE.md). It says what is in, what is
explicitly out, and why.

6.4.0 follows 6.3.1 directly. Each line enters this file with the pull request that carries it.

## In

| Identifier | What changes | Carried by |
|---|---|---|
| Z410-j1 | `loads_strict` refuses `NaN`, `Infinity`, `-Infinity` and every number that becomes infinite, with `BundleFormatError`, the error it raises for a duplicate member. | Z410 |
| Z410-j2 | `loads_strict` refuses an integer literal outside plus or minus 2^53 - 1 (RFC 7493 section 2.2), the range the Rust verifier `pb_verify_rs` reads, so both verifiers give the same bytes the same verdict. | Z410 |
| Z410-j3 | `loads_strict` refuses JSON bytes with a UTF-8 byte order mark or in UTF-16 or UTF-32. | Z410 |
| Z410-j4 | The SD-JWT checks (header, payload, disclosures) and the KB-JWT check name the reader's reason in their detail, bounded to 200 characters, instead of a fixed duplicate-key text. | Z410 |

The identifiers above carry a lower-case part after the dash so that `scripts/b7_release_scope_title_gate.py` reads
each as its own identifier and not as `Z410`.

The branch below carries the lines above.

| Identifier | What it carries | Branch |
|---|---|---|
| Z410 | Z410-j1 to Z410-j4, four lines | `fix/loads-strict-only-json-numbers` |

Each pull request names its line in its title, `[6.4.0 <Identifier>] type(scope): subject`, with the identifier of the
branch table, so the landing card can count it.

## Out, and why

| Item | Why not in these lines |
|---|---|
| The Rust side of the I-JSON bound | `pb_verify_rs` already reads plus or minus 2^53 - 1; by order it is measured and named, not changed. |
| The state line of S104 in `RESTRISIKO_600.md` | The bytes of that register are bound by `RESTRISIKO_600_OBJEKTKLASSEN.json` and its evidence files; the line goes with the next re-cut of that carrier. |
| The register lines of 6.3.0 and the lines of 6.3.1 | They stay in their own scope files with their recorded state; this file does not reopen them. |

The heading `## Out` above is where the scope of 6.4.0 ends. `scripts/b7_release_scope_title_gate.py` reads the lines
above it as the scope.

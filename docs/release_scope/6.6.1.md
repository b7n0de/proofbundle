# Release scope — 6.6.1 (PATCH)

Written before the release, per the release gate in [RELEASE.md](../../RELEASE.md). It says what is in, what is
explicitly out, and why. 6.6.1 follows 6.6.0.

Every row under In corrects a verdict, a wording or a record, and none adds an obligation for a caller. Four rows
change an answer of a public interface, and each says so, as its CHANGELOG entry does: PR544, PR537 and PR471 refuse
input that 6.6.0 accepted, and PR532 changes the wording of the inclusion line and adds one member to an object of
`verify --json`, with the verdict and the exit code unchanged. PR539 and PR551 change exit codes of the Rust
cross-verifier under `tools/`, which the package does not install. The CHANGELOG section of 6.6.1 names each of these
answers, as the sections of 6.3.1 and 6.2.1 do.

### Why 33 of these 34 rows carry no identifier

That is a limit of reading rather than carelessness, and it is measured. The identifier can be
derived mechanically only from the title marker `[6.1.0 X]` that
`scripts/b7_release_scope_title_gate.py` enforces. Exactly one pull request carries one: #224 with
`[6.1.0 P19]`.

The gate demands an identifier only when the **head branch** appears in the scope file — it checks,
in its own output, the head branch against the scope file and never the diff. The previous version of
this file named 47 branch names and said in its own line that none of them was created; they were
the names from the E1 sheet. Of the 34 landed pull requests exactly one carries such a name. Twelve
landed after the gate existed and not one was ever asked for an identifier; the gate answered
"outside the scope" every time and was green.

A gate that binds on a key the work does not carry is neither red nor broken — it simply never
demands anything. Recorded as finding `TOR-BINDET-AM-ZWEIGNAMEN-DEN-NIEMAND-BENUTZT-01`.
**Assigning identifiers to the remaining 33 rows after the fact would be a reading, not a
measurement**, and an invented identifier is worse than a named gap. They carry `—`.

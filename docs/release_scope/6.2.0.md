# Release scope — 6.2.0 (in progress)

## The measure

A line belongs in 6.2.0 when it brings one of the four outcomes closer, or closes a P1 from the
audit of 2026-09-19, or closes a place where the verifier says more than it checks, or is a
precondition of one of those. Everything else waits. The four outcomes are E1 a second
implementation, E2 in-toto PR 575, E3 three external users, E4 adoption into a specification.

This file replaces the cast of 2026-09-19, which moved 54 lines here unchanged because the cut had
to happen faster than the reading. The lines below were read against the code and the register
before they were placed. Where a finding disagreed with the template, the line stayed and the
disagreement is written down rather than resolved silently.

### N18, measured

A bare `pip install proofbundle-6.1.0.tar.gz` followed by `pytest` in the extracted sdist exits 2,
a collection error, and the run is interrupted after 19 collected tests:

```
ERROR tests/test_action_input_injection.py
tests/test_action_input_injection.py:21: in <module>
    import yaml
E   ModuleNotFoundError: No module named 'yaml'
```

It is one file and one line. Of the six test modules that import an optional dependency, five guard
it with `pytest.importorskip` and this one does not. The invariant the CI step claims to pin is the
one it does not exercise: `published-artifact-gate.yml` installs the `[test]` extra and only then
runs pytest, so the bare case never executes there.

### C1, measured, and the line as written is no longer true

Built with `scripts/build_reproducible.py` from the git tree at `v6.1.0` (`dcac5aee`),
`SOURCE_DATE_EPOCH` from the commit time, which is the one line `release.yml` runs:

```
proofbundle-6.1.0-py3-none-any.whl   published f43164161952d78a…   rebuilt f43164161952d78a…   IDENTICAL
proofbundle-6.1.0.tar.gz             published d63554915940ce42…   rebuilt d63554915940ce42…   IDENTICAL
two runs of the same tree: identical for both artefacts
```

The line reads "sdist bit-reproducible, check or change the build backend". Both delivered
artefacts reproduce bit for bit on the shipped path, so **changing the backend would be the wrong
work**. What remains under this heading is S27, the `egg-info` cache: rebuilding an sdist FROM an
sdist is not a fixed point, measured as one line of difference in
`src/proofbundle.egg-info/SOURCES.txt`, where the rebuild lists `setup.cfg` and the original does
not. The line stays here rather than being deleted, because its subject is not empty; it is smaller
than it says.

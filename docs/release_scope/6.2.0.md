a collection error, and the run is interrupted after 19 collected tests:

```
ERROR tests/test_action_input_injection.py

```

It is one file and one line. Of the six test modules that import an optional dependency, five guard
it with `pytest.importorskip` and this one does not. The invariant the CI step claims to pin is the
one it does not exercise: `published-artifact-gate.yml` installs the `[test]` extra and only then
runs pytest, so the bare case never executes there.

This is the state measured on 2026-09-23. Pull request 253 changed it since: the import goes through
`pytest.importorskip`, and the workflow step now collects before it installs the `[test]` extra.

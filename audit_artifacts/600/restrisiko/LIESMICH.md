# Archive — unchanged excerpts from the published 6.0.0 record

This is an archive. It is unchanged. It carries German technical terms and internal
identifiers from before the naming rule, and it is not maintained as an outward text.

Owner decision of 2026-09-11 (order 20260911T2233Z): the historical excerpts stay
byte-identical and are marked as an archive; the generated English surface stands beside
them. Both are bound by digest, neither is quietly cleaned up. The identifier check and
the language check run over the generated surfaces and over new texts — this path is an
EXEMPT AREA, stated with its reason in the generator's configuration, never a silent
exception. Whoever quotes from here into a new outward surface produces a derivation
marked as such, and original and derivation are each bound.

`MANIFEST.json` names, for every excerpt, the pinned source state, its digest and the
byte range it was cut from; `make restrisiko-archiv-pruefen` re-derives every range from that
state and compares byte for byte, so this directory can be checked rather than believed.

The public generated edition contains no bytes from this directory. It points here.

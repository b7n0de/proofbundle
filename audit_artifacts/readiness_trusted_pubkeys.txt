# Trusted ed25519 public keys (base64, raw 32-byte) that may sign a RELEASE-EVIDENCE artifact —
# the recorded fuzz-soak, the Python<->Rust differential matrix, and every other artifact a
# RELEASE-DECIDING check in scripts/audit_candidate_matrix.py admits.
#
# The gate reads this file from the COMMITTED tree (`git show HEAD:...`), never from the working
# tree: reading the working tree would let a dirty checkout inject a key and self-attest evidence
# (the same reasoning as audit_artifacts/pre_tag_trusted_pubkeys.txt, Spur-2 lens A, 2026-08-27).
#
# The PRIVATE half of each key is a release secret held by the RUNNER (CI / owner), NEVER in this
# repo. An EMPTY file (only comments) = NO trust anchor: every release-deciding artifact read then
# fails closed. That is the state today, on purpose — see below.
#
# WHY THIS FILE IS EMPTY, and why that is the honest state rather than an oversight
# (deep gate 2026-09-05, finding L5-G7-02, P2). Until this file existed, checks C6.2/C6.3/C8.2
# granted PASS from UNSIGNED, version-free JSON: a 3.6.0-scoped soak artifact decided 6.0.0, a
# two-key JSON decided "0 crash, 0 false-accept", and `{"all_agree": true}` decided "Python == Rust
# on all" over zero vectors. Adding the mechanism without a key makes those rows RED, and red is
# what they should have been all along. A key is added here in an owner-approved commit as part of
# a release ceremony, together with re-run, candidate-bound evidence signed by its private half
# (scripts/sign_readiness_artifact.py).
#
# Separate from pre_tag_trusted_pubkeys.txt ON PURPOSE: a key that may attest routine release
# evidence must not thereby be able to sign a pre-tag audit receipt. Two trust anchors, two scopes.

# LINE FORMAT, one key per line (Auflage C3, second half, 2026-09-06):
#
#     <base64 raw 32-byte ed25519 public key> role=<role> not_after=<YYYY-MM-DD>
#
# BOTH FIELDS ARE MANDATORY, and a line missing either is DISCARDED — not read as "a key without
# restrictions". Before this format the anchor was a flat list of bare keys: it said WHO may sign,
# but not WHAT FOR and UNTIL WHEN. `signer_role` in an artifact was therefore checked only for
# PRESENCE — a field the producer writes itself, verified against nothing. A role the audited party
# assigns to itself is not a role.
#
#   role        what this key may speak for. The gate compares it to the artifact's `signer_role`
#               and refuses a mismatch: the ANCHOR decides what a key attests, not the artifact
#               that wants to be admitted. Use one role per purpose (e.g. `release-runner`), never
#               a catch-all — the point of the field is that it can fail to match.
#   not_after   last day this key may produce evidence, compared against the artifact's
#               `produced_at` (the moment of MEASUREMENT), not against "now". Evidence that was
#               lawful yesterday does not become inadmissible because the matrix runs today, and
#               evidence produced after the window does not become lawful by being read early.
#
# The stricter format costs nothing today precisely BECAUSE this file is empty: there is no
# existing entry a tighter reading would break. That is why the format is fixed now — later, every
# tightening would be a break.
